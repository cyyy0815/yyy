# 简历工坊 · JD 助手（浏览器扩展）

从招聘网站抓取岗位描述，一键发送到本地简历工坊的「待投清单」。

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），开启右上角「开发者模式」
2. 点「加载已解压的扩展程序」，选择本仓库的 `extension/` 目录
3. 打开简历工坊（默认 `http://localhost:3000`），再打开任意一个岗位详情页
4. 点扩展图标 → 确认抓到的公司 / 岗位 / JD → 「发送到简历工坊」

应用会自动切到「职位推荐」页并打开「批量导入」弹窗，确认后进入待投清单。

## 工作方式

```
岗位页 (content-job.js) → popup → background.js
        → 简历工坊页面里的 content-app.js → window.postMessage → 页面
```

- 扩展只做传递，**不保存 JD**，也不访问任何服务器
- 页面只接受 `source === "resume-workshop-extension"` 且 `type === "lead"` 的 `window` 消息
- 内容按纯文本渲染，不走 `innerHTML`

## 支持站点

BOSS直聘、拉勾、猎聘、智联招聘、前程无忧。抓取策略是「多候选选择器 → JSON-LD → 正文兜底」，
平台改版后选择器可能失效：此时弹窗里会留空，**手动粘贴 JD 后照样能发送**。

## 应用地址

默认 `http://localhost:3000`。如果应用跑在别的端口，在扩展弹窗的「应用地址」里改；
扩展只注入该地址下的页面，地址不一致会提示「没能连上简历工坊页面」。

## 自动填表（P3.2）

在投递表单页点扩展图标 →「填充当前页表单」：

- 从**已打开的简历工坊页面**读取姓名 / 手机 / 邮箱 / 期望城市 / 期望岗位 / 简介（只走内存，不写扩展存储）
- 按标签、placeholder、`aria-label`、`name`/`id` 匹配字段，只填空字段，不覆盖你已经输入的内容
- **不点提交**、**不碰身份证 / 银行卡 / 密码 / 验证码**（命中这些关键词的字段直接跳过）
- 填充的字段会有 2.5 秒蓝色描边，方便确认
- **简历附件仍需手动上传**：扩展拿不到本地文件，也不应该替你决定投哪份

匹配策略是「猜标签」，不同平台、不同表单差别很大；填不上的字段会在弹窗里列出来。

## 真实站点验证（2026-10-29）

在**未登录**的 Chrome 里对公开岗位页跑过真实提取：

| 站点 | 结果 |
|---|---|
| 智联招聘 | ✅ 可匿名提取：公司取 `a[href*="/companydetail/"]`、岗位取 `.summary-planes__title`、正文由「按『职位描述』标题向上找容器」的通用兜底拿到；已按真实 DOM 修正（之前写成 `.summary-plane__title`，少了个 s 所以全空） |
| BOSS直聘 | ⚠️ 未登录访问岗位页直接跳 `/web/user/` 登录页，匿名状态无法验证 |
| 拉勾 | ⚠️ 出现「滑动验证」页 |
| 猎聘 | ⚠️ 列表页被风控打到 `about:blank`，无法验证 |
| 前程无忧 | ⚠️ `we.51job.com` 是 SPA，未登录时列表不渲染职位卡片 |

登录后的详情页 / 表单页请用弹窗预览自检：公司、岗位、JD 都有值说明选择器仍然有效；
为空时手动粘贴 JD 或直接点「填充当前页表单」试试，不会污染已有数据。
### 诊断模式

弹窗里点「诊断选择器」会回报：

- 每个字段命中的来源（`site:.summary-planes__title` / `jsonld` / `fallback:heading` / `fallback:companyLink` …）
- 站点规则里每条选择器在当前页面的命中数量
- 页面上的 h1 / h2 标题与正文长度

抓不到或抓错时，点一次「诊断选择器」→「复制诊断结果」，把 JSON 贴出来即可按真实 DOM 精确修选择器，不用猜。
诊断只读页面，不修改、不上传任何内容。
## 边界与注意事项

- **不自动提交投递**：平台没有公开 API，自动提交违反其条款且容易封号；扩展只负责抓 JD、传递与填表
- **不抓列表页、不批量爬取**：只在当前岗位详情页按需提取
- **不保存账号**：扩展不读取 Cookie，也不需要登录信息
- 扩展需要 `tabs` 与 `storage` 权限：前者用于找到/打开简历工坊标签页，后者只存「应用地址」
- 平台条款仍适用；请勿用它做高频自动化操作
