## 怎么跑起来

```bash
# 1. 安装依赖（Node.js 20+）
npm ci

# 2. 配置环境变量
cp .env.example .env.local
#    编辑 .env.local，填入 DEEPSEEK_API_KEY（不填也能跑，只是 AI 步骤会被跳过）

# 3. 启动
npm run dev          # http://localhost:3000
```

生产模式：

```bash
npm run build && npm run start
```

## 怎么看

1. 打开首页 → 顶栏点「**演示场景**」，载入示例简历与 3 个目标岗位
2. 在「待投清单」里点任意岗位的「**准备**」
3. 点「**启动求职 Agent**」→「自动执行本地步骤」→ 第三步「执行」看流式改写与事实核对
4. 顶栏「打印 / PDF」可看排版与分页

> 数据存在浏览器本地，换设备或清缓存就是空的——这是隐私优先的设计，不是 bug。

## 自检与评测

```bash
npm test          # 274 个单元 / 组件用例
npm run eval      # 生成 docs/eval-report.md（离线评测：画像识别、分组收益、事实核对）
npm run qa        # 需要先 build + start，浏览器端到端 237 项
npm run preflight # 推送公开仓库前的自检
```

## 浏览器扩展（可选）

`源码/extension/` 是一个 Chrome MV3 扩展：在招聘网站抓取当前岗位 JD、填充投递表单、诊断选择器。
安装方式：`chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → 选择该目录。
