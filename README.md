# 简历工坊 (Resume Workshop)

浏览器里的简历制作 + 求职搜索推荐工具。简历数据只保存在本机 localStorage，无账号、无云端同步。可选的「AI 写简历」通过本项目的 Next.js 服务端路由调用 DeepSeek，API Key 不会进入浏览器。

参考 UP简历 的基础能力，并增加了「根据简历内容推荐国内招聘网站搜索入口」的功能。

## 功能

### 简历制作

- 左表单 / 右 A4 实时预览
- 基本信息、求职意向、工作经历、项目经历（含起止时间）、教育经历（GPA、排名、主修课程、荣誉可选）、技能标签
- 技能分组与熟练度：新建 / 重命名 / 删除 / 上下移动分组，逐个技能标记「了解 / 熟练 / 精通」；删除分组只解除归属，不删技能。分组只影响展示，匹配与 AI 仍读取全部技能
- 可选证件照：上传后自动居中裁成 400×400 JPEG 并压缩，八套模板均有照片位；只保存在本机
- 自定义板块：证书、获奖、语言、校园经历、作品集或空白板块；条目增删、上下排序，板块可隐藏
- 网站、GitHub、项目与自定义板块链接在预览和导出的 PDF 中可点击；自动补全 `https://`，过滤 `javascript:`、`data:` 等危险协议
- 多份简历：文档栏新建、复制、重命名、切换、删除；每份独立保存内容与模板；复制后可到职位推荐页按 JD 调整
- 经历条目支持增删、拖拽排序（移动端保留上下按钮）；删除后 8 秒内可撤销
- 全局撤销 / 重做：编辑区顶部按钮或 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`（`Ctrl+Y`）；连续输入合并为一步，最多保留 60 步；切换、新建或导入简历时清空历史。输入框内保留浏览器原生文本撤销
- 刷新页面后撤销 / 重做仍可用：历史写入 `sessionStorage`，最多保留 20 步并受 1.5MB 体积预算约束（照片较大时自动丢弃最旧步骤）；关闭标签页后清空，切换简历时同步清除
- 导入 JSON、载入示例覆盖当前简历前需要确认；存储写入失败时提示导出备份
- 8 套模板：现代（双栏）、经典（衬线单栏）、紧凑（高信息密度）、侧栏（左侧深色信息栏）、时间轴（经历时间线）、极简（单栏大留白）、学术（居中双线抬头）、卡片（板块独立成卡片）
- 5 种字体搭配：默认（沿用模板字体）、无衬线、衬线、报刊（衬线标题 + 无衬线正文）、等宽（等宽标题 + 无衬线正文）；只改标题与正文，不改字号与分页，随简历保存
- **简历语言**：中文 / 英文 / 双语三种模式。英文与双语模式下可填写英文内容（姓名、头衔、城市、简介、求职意向、经历、项目、教育、技能名称与技能分组、自定义板块），留空自动回退中文原文；板块标题、至今 → Present、工作类型 / 学历 / 年限 / 熟练度等固定文案随语言切换，八套模板、打印与 ATS 导出同步。双语模式中英文并列，中文数据始终是唯一事实来源
- 主题色：8 种预设 + 任意自定义颜色，随简历保存；浅色会自动压暗，保证正文与侧栏文字可读
- 按目标岗位推荐缺失技能，点击即可添加
- 防抖自动保存到 localStorage，显示「保存中 / 已保存」与最后保存时间；超过 7 天未导出时提醒备份，可暂停 3 天
- 多标签页同时编辑时检测冲突并暂停保存，由你选择「重新载入对方版本」或「保留本页版本」，避免静默覆盖；只是开着、还没编辑过的标签页会自动跟随最新版本，不会误报冲突
- 失焦校验邮箱、手机号、链接、薪资区间与起止时间，不阻断写作
- A4 页数估算，超过 1 页时提示精简；预览工具栏「一页适配」实时显示页数，可隐藏建议项、恢复打开时状态或换用紧凑模板
- 手动分页：工作 / 项目条目可设置「从此条起另起一页」，预览中显示分页标记
- 整库 JSON 备份：一次导出全部简历（当前文档 + 文档列表，含照片、自定义板块、主题色与模板），导入时整体替换并恢复当前文档；旧版单份 JSON 仍可导入；校验结构、字段类型与 5MB 大小上限
- **数据版本**：简历与单份 / 整库备份都带 `schemaVersion`；旧版裸 JSON 与旧备份自动补齐当前结构，来自更新版本的备份会明确拒绝导入，避免旧程序静默丢字段
- **单份导出与合并导入**：简历栏「导出当前」只导出这一份简历，便于单独分享，不含其他简历与投递记录；「合并导入」可追加单份简历或整库备份，不覆盖现有简历与投递记录，也不切换当前正在编辑的简历，标题冲突自动编号（如「前端简历 2」）
- **ATS 文本导出**：预览工具栏「ATS 文本」可导出线性纯文本或 Markdown，去掉照片、分栏、主题色与技能等级，方便招聘系统解析；弹窗自动读取已保存 JD，实时显示关键词覆盖率与未覆盖词，支持下载 `.txt` / `.md`
- **AI 事实核对**：AI 单段写作、整份生成与求职信预览下自动列出素材里找不到依据的数字、技能与学校 / 公司 / 项目名；只提示、不改写、不阻止采用，参考 JD 不计为事实来源
- **板块显示与排序**：编辑区可上下移动或隐藏个人简介、工作经历、项目经历、自定义板块、教育经历、专业技能、求职意向；全部模板与 ATS 导出同步遵守，隐藏只影响预览 / 打印 / 导出，不删除内容
- **一页适配**：弹窗按当前模板实时显示 A4 页数，可逐项开关板块、一键隐藏建议项（求职意向、自定义板块）、恢复到打开时状态或换用紧凑模板，内容不会被删除
- 手机端也可导入 JSON
- 浏览器打印导出 PDF：只输出简历，A4 全宽；首页贴顶、续页上下留白，页脚自动带「第 N / M 页」页码，可一键关闭页码；默认文件名取「姓名-求职头衔」
- 编辑与错误页面兜底：自定义 `error.tsx` / `global-error.tsx` / `not-found.tsx`，出错时可直接重试或刷新
- **键盘与弹窗体验**：五个业务弹窗统一焦点陷阱、关闭后归还焦点、`Esc` / 点击遮罩关闭与背景滚动锁；提供「跳到主要内容」链接、键盘焦点环与 `prefers-reduced-motion` 降级
- **离线可用（PWA）**：成功访问一次后，Service Worker 会缓存应用外壳、构建静态资源与图标；断网时仍能打开、编辑、预览、打印、导入导出 JSON 并保存到本机，页面顶部显示离线提示。AI 写作与招聘网站链接需要联网；新版本下载完成后底部提示刷新，不会打断正在编辑的内容

### AI 写简历（可选，需配置 DeepSeek Key）

- 个人简介 / 工作经历 / 项目经历三个板块，按目标岗位、年限、关键词生成
- **跟随简历语言**：中文 / 英文 / 双语模式下，单段写作、整份生成与求职信都按当前语言输出；英文写入英文覆盖层，双语拆成原文与英文两部分，提示词、预览与事实核对同步
- **双语输出**：单段按 `===EN===` 分隔行拆成两个可编辑预览；整份生成额外返回 `english` 覆盖对象，按条目顺序写入，英文缺失时回退中文
- **整份简历生成**：写一段个人经历自述（毕业时间、公司、项目、技能等），AI 一次返回结构化简历（简介、教育、工作、项目、技能）；采用时新建一份简历并切换过去，当前简历保留在文档列表
- **AI 求职信**：在推荐页按目标岗位、工作年限、个人素材与参考 JD 生成求职信；输出语言默认跟随简历，也可在弹窗中单独切换中文 / 英文 / 双语；默认素材取自简介与前 12 个技能，结果可编辑、复制或下载 `.txt`，不会写入简历
- 整份生成不编造事实：自述里没提到的公司、时间、技能会留空，并在预览中列出待补充项；不生成姓名、邮箱、电话等联系方式
- 生成后自动做事实核对：列出素材里没有的数字、技能与名称；无问题时显示绿色确认。核对只做字面比对，同义改写可能漏报
- **参考 JD 定制**：自动读取 JD 匹配页保存的目标 JD（最多 4000 字），按 JD 调整表述重点；JD 只作为参考，不编造你没写过的经历与技能
- 「优化现有内容」模式不强制填写关键词，可只提交当前板块文本
- 流式预览，生成中可停止；生成结果可以直接修改后再采用
- 写入现有条目（替换或追加）或新建工作 / 项目条目
- 覆盖非空内容需二次确认；采用后 8 秒内可撤销，新建条目的撤销会一并删除该条目
- 个人简介保持单段；工作 / 项目输出 3–5 条要点
- 未配置 Key 时弹窗内显示配置步骤，不影响原有编辑
- 单板块生成只发送当前板块、面板填写内容与参考 JD；整份生成只发送这段自述、目标岗位与参考 JD；求职信只发送目标岗位、工作年限、个人素材与参考 JD。服务端会过滤邮箱、手机号、链接，三种情况都不发送姓名与现有简历内容
- 生成内容会发送到 DeepSeek；请勿在关键词或 JD 里粘贴敏感信息

### 求职推荐

- 本地岗位画像库（前端、Java / Python / Go 后端、全栈、数据工程、产品、设计、数据、测试、算法、运营、移动端、运维、网络安全、销售/商务、售前/实施、供应链/采购、法务/合规、行政/助理、市场营销、财务/会计、人力资源、客服/客户成功、教师/培训、嵌入式）
- 推荐页门槛放宽：期望岗位、简介、技能或任意一段经历/教育内容都可进入分析
- 技能命中分析：同时扫描技能标签与经历/项目/简介正文，避免 `Java` 误命中 `JavaScript`
- 内置技能同义词：`JS` / `TS`、`K8s`、`Golang`、`Postgres`、`SpringBoot`、`CPP` / `CSharp` 等归一到规范写法；仍区分 `C` / `C++` / `C#`，JD 关键词按规范标签去重
- 匹配分 = 核心要求 55% + 加分技能 20% + 简历完整度 25%；核心要求按「同族技能任选其一」计算（只会 React 也算满足前端框架要求，不会因为没写 Vue 被扣分），分数下方会显示三项构成
- 输出缺失要求与简历优化建议；缺失的具体技能可点击补进简历（同族要求合并成「React / Vue」这样的提示，不会把组合词写进技能标签）
- **粘贴目标 JD 测匹配度**：技能关键词覆盖率、年限/学历要求核验、缺口建议，JD 内容仅保存在本机；「简历未体现」的技能可一键加入简历
- **投递看板与多 JD**：按想投 / 已投 / 面试中 / Offer / 未通过五列管理投递；每条记录独立保存 JD、求职信、备注与下一步日期，任意一条 JD 可设为「当前 JD」供匹配和 AI 求职信使用
- **待投清单与批量 JD**：一次粘贴多条岗位描述（`---` 分隔，首行「公司 | 岗位」），按当前简历的匹配度排队；点「准备」可设该 JD 为当前 JD 并直接打开 AI 求职信，也可「按 JD 优化简历」（切到编辑页打开 AI 写作，已带这条 JD）或一键下载 ATS 文本；投完标记已投并设置跟进日期
- **求职 Agent**：待投清单里点「启动求职 Agent」，按「解析岗位 → 诊断差距 → 按 JD 改写简介 → 生成求职信」四步执行；前两步纯本地、不发数据，后两步流式生成并强制事实核对，结果需手动采用（可撤销），全过程记录工具调用与耗时
- **浏览器扩展（可选）**：`extension/` 里的 Chrome MV3 扩展从 BOSS直聘 / 拉勾 / 猎聘 / 智联 / 前程无忧的岗位页抓取 JD，一键发送到待投清单；在投递表单页还能一键填充姓名 / 手机 / 邮箱 / 期望城市等文本字段（不提交、跳过身份证与密码、附件手动上传）
- 生成 BOSS直聘、拉勾、猎聘、智联招聘、前程无忧的精准搜索链接
- 支持城市参数（BOSS直聘覆盖 40 个城市编码，拉勾/智联带城市名）

> 招聘平台没有公开的职位 API，本工具不抓取职位数据，只生成合法合规的搜索入口；职位以平台实时结果为准。

## 技术栈

- Next.js 16（App Router）+ React 19 + TypeScript

### AI 配置（可选）

不配置 Key 也能使用全部简历编辑与求职推荐功能，只是 AI 弹窗会显示配置步骤。

1. 复制示例文件：

   ```bash
   cp .env.example .env.local
   # Windows PowerShell: copy .env.example .env.local
   ```

2. 填入 DeepSeek Key：

   ```dotenv
   DEEPSEEK_API_KEY=sk-...
   DEEPSEEK_MODEL=deepseek-flash
   DEEPSEEK_BASE_URL=https://api.deepseek.com
   ```

   - `DEEPSEEK_API_KEY`：必填，只在服务端读取。
   - `DEEPSEEK_MODEL`：默认 `deepseek-flash`；也可换成账号可用的其他模型。
   - `DEEPSEEK_BASE_URL`：默认 `https://api.deepseek.com`，一般不用改。
   - `TRUSTED_PROXY_HOPS`：默认 `1`。AI 接口按 IP 限流时，只采信 `X-Forwarded-For` 里由你的反向代理追加的那一跳（最右侧），客户端自己写的最左侧地址不参与计数。单层代理（Nginx / Vercel / Cloudflare）保持默认；`CDN + Nginx` 两层填 `2`。

3. 重启 `npm run dev`（修改 `.env.local` 后需要重启）。

`.env.local` 已被 `.gitignore` 忽略。不要把 Key 写进 `NEXT_PUBLIC_*`、前端代码、localStorage 或导出的 JSON。

### 用 mock 联调（不消耗额度）

```bash
node scripts/mock-deepseek.mjs
# 另开终端：
DEEPSEEK_API_KEY=test DEEPSEEK_MODEL=mock \
DEEPSEEK_BASE_URL=http://127.0.0.1:8787 npm run dev
```

- `public/sw.js` 只在生产环境注册；`/sw.js` 以 `no-store` 下发，保证及时更新。开发模式会主动注销旧 SW 并清理缓存，避免 HMR 读到旧资源

- 公网部署时设置 `NEXT_PUBLIC_SITE_URL=https://你的域名`；否则 OG 图片地址会使用请求域名（本地为 localhost）

## 隐私与部署

- 简历与 JD 只保存在浏览器 localStorage；撤销历史只存在当前标签页的 sessionStorage，关闭标签页即清空；没有账号与云同步。
- AI 只把当前板块文本、目标岗位、年限、关键词发给 DeepSeek；服务端会移除邮箱、手机号、网址和 GitHub 链接。日志只记录状态码、耗时和 token 数，不记录 Key、提示词或生成内容。
- 生成接口边读边计数，请求体超过 64KB 立即中断，不会先把整段 body 读进内存；同时校验 `Origin` / `Sec-Fetch-Site`，只接受同源页面发起的请求，第三方站点无法借访客的 IP 与你的 Key 消耗额度（返回 403）。
- 按 IP 做简单限流（10 次 / 10 分钟，内存实现；限流桶有上限并回收过期项）。IP 取 `X-Forwarded-For` 最右侧一跳，代理层数用 `TRUSTED_PROXY_HOPS` 指定。多实例部署需换成 Redis / KV 等共享存储；公网部署建议再加登录或访问控制。
- 全站响应头包含 CSP、HSTS、`nosniff`、`X-Frame-Options: DENY`、严格 Referrer-Policy、Permissions-Policy、COOP / CORP，并关闭 `X-Powered-By`。生产 CSP 不含 `unsafe-eval`；开发模式仅为 React 调试与 HMR 放行 eval 和 WebSocket。CSP 保留 inline script / style 以兼容 Next 启动脚本与行内样式；如需严格 nonce CSP，需要改为动态渲染。
- AI 路由需要 Node.js 运行时（`next start` 或 Vercel 等），不能再使用纯静态导出；不要从浏览器直连 DeepSeek。
- 公网部署建议设置 `NEXT_PUBLIC_SITE_URL`（例如 `https://resume.example.com`），让 OG / Twitter 分享图使用绝对地址；未设置时 Next.js 会退回请求域名。
- 生产环境注册 Service Worker，缓存应用外壳、构建静态资源与图标，方便添加到主屏并离线打开。缓存不含简历内容、导入文件、AI 请求或响应；简历数据仍只存在 localStorage。首次访问必须联网，开发模式不注册 SW。

## 已知边界

- 不做真实职位抓取、账号体系、云端同步
- 推荐页展示的是搜索入口，不是职位列表
- AI 支持三个单板块写作、整份结构化生成与求职信，输出语言跟随简历；非 AI 生成的英文 / 双语内容仍由你手动填写，不做机器翻译
- AI 以中文原始数据作为素材与事实来源；英文输出写入覆盖层或英文主字段，不会改写中文原文（双语单段会同时写入两边）
- 英文 / 双语展示由英文内容与内置固定文案组成；日期、链接、GPA 等自由文本按原样展示，需要自行填写英文写法
- 推荐匹配与事实核对读取中文原文（技能也一样），切换语言不会改变推荐分数
- AI 生成内容需要人工核对，尤其是数字、项目结果与时间；模型可能给出不准确的表述
- 超长简历会自然跨页，页码由浏览器按 `@page` 自动生成；预览中的页数、分页线为估算值（手动分页与条目内空隙无法精确预判），实际以打印预览为准
- 双栏模板打印时改为「浮动侧栏 + 固定栏宽正文」：正文可正常跨页，续页保持同样栏宽；侧栏内容超过一页时，侧栏会连同底色一起延续到续页
- 打印页码依赖 Chrome / Edge 的 `@page` margin box，Firefox 与 Safari 不会显示「第 N / M 页」，但简历正文、分页与配色仍可正常打印。导出 PDF 建议使用 Chrome / Edge；其他浏览器可在打印对话框中关闭页眉页脚，或关闭本工具的页码开关后自行添加页码
- 证件照只在浏览器内压缩为 400×400 JPEG，不保留原图，也不做抠图或美颜；照片会增加 JSON 备份与 localStorage 的体积
- 多份简历只保存在当前浏览器；JSON 导出会包含全部简历，导入整库备份会替换当前全部简历（操作前会确认）；删除简历不可撤销
- 离线缓存覆盖应用外壳与构建静态资源，不含 AI 接口、招聘站内容或简历数据；首次访问必须联网，清空浏览器站点数据会同时清掉缓存。开发模式不注册 SW，离线行为只能在生产构建（`npm run build && npm run start`）验证
- 浏览器扩展只做「读当前岗位页 → 发送到本地应用」与「按标签填充投递表单的文本字段」，不自动提交投递、不抓列表页、不保存登录态、不填身份证 / 银行卡 / 密码；招聘平台改版后提取与填表的选择器可能失效，此时在扩展弹窗里手改或直接粘贴即可
- 分享卡片文案为英文：`ImageResponse` 默认字体不含中文字形，直接渲染中文会变成方框
- 字体搭配只使用系统字体栈，不下载或嵌入字体文件；不同系统上的衬线 / 等宽字形由本机字体决定。字体不改字号与行高，不能替代内容精简或一页适配
