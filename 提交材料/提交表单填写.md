`提交材料/简历工坊-完整作品.zip`（约 6 MB），里面已经分好目录：

```

├── 界面截图/               4 张原图
```

### 上传建议

1. 上传到百度网盘 / 夸克 / 阿里云盘任意一个
2. 分享设置：**永久有效** + **提取码**（建议 4 位数字或字母，自己记一下）
3. 不要把提取码写进链接里，表单里分开填
4. 上传完成后，**用无痕窗口打开一次分享链接**，确认能下载

### 表单里填什么

```

提取码：abcd
```

（如果是夸克/阿里云盘，链接格式不同，照实填即可。）

## 第 7 项：演示视频地址（B 站/抖音）

**必须用公开视频平台**，不能是网盘链接。推荐 B 站（可加字幕、可设公开）。

### 上传步骤（B 站）

1. 打开 https://member.bilibili.com/platform/upload/video/frame

## 附：表单可能需要的一段话（150 字 / 300 字）

**150 字版**

> 简历工坊是一个本地优先的求职工作台：用浏览器扩展把真实招聘网站的 JD 抓进来，按「核心要求分组」给出可解释的匹配分与缺口；再由求职 Agent 规划步骤——解析岗位、诊断差距、按 JD 改写简介、生成求职信，生成结果经事实核对后由用户手动采用。简历与投递记录只存在本地，AI 只接收必要字段。

**300 字版**

> 简历工坊解决的是求职者最实际的三件事：看不懂岗位、改不动简历、记不住投递。
>
> 它用 Chrome 扩展从 BOSS直聘、智联、猎聘等站点抓取当前岗位的 JD，经本地消息桥进入待投清单；匹配引擎把岗位要求建模成「同族技能任选其一」的要求组，给出核心要求、加分技能与完整度的分值构成，并指出具体缺口（例如「浏览器与性能优化」）。
>
> 求职 Agent 是核心：模型先规划执行步骤（工具白名单校验，失败自动回退本地计划），本地工具完成解析与诊断后，观察回灌给模型重新规划；AI 改写与求职信采用流式输出，生成后本地核对数字与技能是否超出素材，必须手动采用才写入简历且可撤销。
>
> 数据只存在浏览器本地，服务端仅做 AI 代理；AI 只接收当前板块文本、岗位关键词与参考 JD，不发送姓名、电话、邮箱。项目含 274 个单元测试、237 项浏览器端到端检查，并提供 `npm run eval` 可复现的离线评测。
