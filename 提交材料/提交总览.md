## 三、仓库上线步骤

### 1. 改作者信息（历史 + 后续）

```bash
# 后续提交
git config user.name "你的名字"
git config user.email "你的邮箱"

# 历史提交（无 remote 时零风险；改完用 git log 检查）
git filter-branch --env-filter '
export GIT_AUTHOR_NAME="你的名字"; export GIT_AUTHOR_EMAIL="你的邮箱"
export GIT_COMMITTER_NAME="你的名字"; export GIT_COMMITTER_EMAIL="你的邮箱"
' -- --all
```

> 当前提交者是 `c <c@localhost>`，公开后会显示在每个提交里，建议改完再推。

### 2. 补 README 团队信息

`README.md` 末尾的「团队信息」表格，填姓名 / 学校 / 分工（示例已给出）。

### 3. 推送

```bash
git remote add origin <仓库地址>
git push -u origin main
```

### 4. 推送后确认

- 网页端能匿名打开仓库（无登录窗口）
- README 在仓库首页正常渲染，截图可见
- `提交材料/` 里的 PDF 能在网页端预览（GitHub 支持 PDF 预览）
