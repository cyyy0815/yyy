## 项目简介

简历工坊是一个本地优先的求职工作台：把「看懂岗位要求 → 判断匹配 → 定向修改简历 → 准备求职信 → 记录投递」串成一条可解释的链路。简历与投递记录保存在浏览器本地；服务端只承担 AI 代理，不存简历、不收集联系方式。

核心能力：

- 8 套 A4 模板、字体搭配、中英双语、分页与页码；
- 可解释的匹配分、核心要求分组与可点击的技能缺口；
- 求职 Agent：计划 → 工具 → 轨迹，AI 结果经过事实核对与人工采用；
- 无需安装插件的采集书签：在招聘网站搜索结果页读取当前页岗位，回到应用粘贴预览；
- 导出 Word / PDF / ATS 文本，支持 PWA 离线打开。

## 本地运行

```bash
npm ci
cp .env.example .env.local   # 填入 DEEPSEEK_API_KEY；不填也能跑，AI 会降级
npm run dev                  # http://localhost:3000
```

生产模式：

```bash
npm run build && npm run start
```

环境变量说明见仓库根目录 `.env.example`；依赖清单位于 `package.json` / `package-lock.json`。
